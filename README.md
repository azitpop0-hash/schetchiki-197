# Счётчики 197 — APK-обёртка (WebView)

Внутри APK лежит тот же `assets/index.html`, что и в браузерной версии.
Приложение ничего не грузит из сети: WebView открывает локальный файл,
а показания хранятся в localStorage этого WebView.

## Вариант 1 — сборка в облаке (без ПК)

1. Заведи аккаунт на github.com (если нет) и создай пустой репозиторий, например `schetchiki-197`.
2. Загрузи в него всё содержимое этой папки (можно через веб-интерфейс: «Add file → Upload files», перетащить папки `app`, `.github`, файлы `build.gradle`, `settings.gradle`, `gradle.properties`).
   Важно: папка `.github` должна быть именно в корне репозитория — в ней лежит сборка.
3. Открой вкладку **Actions** → workflow **Build APK** → **Run workflow**.
4. Через 2–4 минуты зайди в завершившийся запуск → внизу **Artifacts** → скачай `schetchiki-apk`.
5. Внутри архива `app-debug.apk`. Скачай его на телефон, открой, разреши установку из этого источника.
   APK подписан debug-ключом GitHub — для личного использования этого достаточно.

## Вариант 2 — Android Studio на компьютере

1. Android Studio → Open → папка с этим проектом.
2. Дождись синхронизации Gradle (скачает AGP 8.5 и SDK 34).
3. Build → Build Bundle(s)/APK(s) → Build APK(s).
4. APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Что меняется по сравнению с PWA

- Иконка и запись в списке приложений, без Chrome и без сервера.
- Данные живут в хранилище приложения (WebView), а не в Chrome.
- Бэкап JSON в «Тарифах» по-прежнему нужен: очистка данных приложения стирает показания.
- Ограничений на локальный сервер нет — файл открывается напрямую.

## Обновление содержимого

Замени `app/src/main/assets/index.html` на новую сборку и повтори сборку.
Номер версии поднимается в `app/build.gradle` (`versionCode`, `versionName`).
